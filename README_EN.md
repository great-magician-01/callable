# callable

**English** | [中文](README.md)

A unified Go LLM calling library: one API that supports **OpenAI (Chat Completions / Responses)** and **Anthropic** wire formats, with a full built-in **agent loop** (tool-call loop, progressive skill disclosure, thinking mode, image input, streaming output).

```
┌─────────────────────────────────────────────┐
│  Agent / Session (auto tool loop + session) │
├─────────────────────────────────────────────┤
│  Client (Create / Stream / retries)         │
├─────────────────────────────────────────────┤
│  Provider adapters (OpenAI / Responses /    │
│  Anthropic, incl. thinking fields of        │
│  Chinese-compatible endpoints)              │
├─────────────────────────────────────────────┤
│  Unified message model (text / image /      │
│  thinking / tool_call / tool_result)        │
└─────────────────────────────────────────────┘
```

## Features

- **Three wire formats**: OpenAI Chat Completions, OpenAI Responses, and Anthropic Messages. Switching is a one-line change in the constructor, and message history is portable across providers.
- **Agent loop**: model → tool execution → model → … runs automatically until the final answer; supports approval hooks (approve / deny / replace args), parallel tool execution, and max-turns protection.
- **Tool calling**: JSON Schema generated by reflecting on an args struct (`invopop/jsonschema`); the handler is the executor. Tool errors are fed back to the model instead of breaking the loop.
- **Web search**: prefers the provider's built-in server-side search (Kimi, GLM/Z.AI, Qwen, Anthropic, OpenAI Responses — auto-sniffed from the BaseURL); endpoints without it can fall back to a Tavily-backed tool (`WithTavilyAPIKey`); explicit on/off via `WithWebSearch`.
- **Multi-turn conversations**: the built-in `Session` maintains history; thinking blocks and tool traces are fully preserved and correctly sent back (Anthropic signature, Responses reasoning item, DeepSeek/GLM reasoning_content).
- **Forward compatibility**: response fields and content blocks the unified model does not map are preserved as raw JSON (`Response.Extra` / `Message.Extra` / `Usage.Extra` / `RawPart`) — gateway additions and newly introduced provider block types are never lost, and unknown blocks replay verbatim when sent back to the same provider.
- **Context management**: sessions track context-window occupancy (`Usage.ContextTokens`, normalized per provider) and support threshold-triggered auto-compaction (`WithAutoCompact`) plus manual `Compact`.
- **Conversation IDs & persistence**: every session/run gets an auto-generated ID (`sess-` / `run-` prefix) stamped onto all streaming events and the `AgentResult`; `Session.Snapshot` / `Restore` persist and resume a conversation in one call each; Sessions are concurrency-safe.
- **Structured output**: `JSONMode` / `JSONSchema` / `JSONSchemaFor[T]` (reflected from a struct) constrain JSON output and map to each provider's native control field; `resp.DecodeJSON(&v)` decodes straight into a Go struct.
- **Sampling parameters**: `WithTopP` / `WithStopSequences` at request level or as Client defaults, mapped per provider (OpenAI Responses has no stop); temperature/top_p are omitted automatically in thinking mode.
- **Request/response hooks**: `WithRequestHook` / `WithResponseHook` observe every model call (including those inside the agent loop) for logging, tracing, and cost accounting.
- **Model listing**: `client.ListModels(ctx)` wraps GET /models (OpenAI-compatible and Anthropic endpoints; Anthropic pagination is followed automatically) and returns a unified `ModelInfo` (ID / DisplayName / OwnedBy / Created).
- **Streaming**: a unified `ThinkingDelta / TextDelta / ToolCallDelta / ToolResult / Turn*` event stream with full visibility into the agent loop.
- **Thinking mode**: a unified `Effort` (low/medium/high) mapped to each provider's native fields; automatically adapts to non-standard thinking fields of Chinese endpoints such as GLM/Zhipu, Volcano Ark, Qwen, and DeepSeek (auto-sniffed from the BaseURL).
- **Progressive skill disclosure**: only a name/description index is injected into the system prompt; the model loads the full text on demand via the built-in `read_skill` tool; a read hook can rewrite the content.
- **Sub-agent delegation**: register named sub-agents (with their own model, prompt, tools, and skills). By default they are **not** added to the tool list — the model first loads them manually via the built-in `load_agent` tool, which dynamically registers a `call_<name>` tool for delegating subtasks.
- **Image input**: pass a local path, URL, or raw bytes; automatically converted to the target provider's format at send time (base64 source / data URL).
- **Zero-dependency network layer**: HTTP retries (exponential backoff on 429/5xx) and SSE parsing are all implemented with the standard library; the only third-party dependency is `invopop/jsonschema`.

## Quick Start

```go
// The second argument is the endpoint URL: constants for common vendors are
// built in (see below); for other endpoints pass the actual URL.
client := callable.NewAnthropicClient(apiKey, callable.AnthropicURL, "claude-sonnet-5")
// Or NewOpenAIClient / NewOpenAIResponsesClient; when you need a ProviderOption
// (e.g. WithRetries), use the two-step form:
// callable.NewClient(callable.NewAnthropicProvider(apiKey, callable.AnthropicURL), callable.WithModel(...))

// Single streaming call
err := client.Stream(ctx, callable.NewRequest(callable.User("Tell me a story")), func(ev callable.Event) {
    if d, ok := ev.(callable.TextDeltaEvent); ok {
        fmt.Print(d.Delta)
    }
})
```

## Agent: The Tool-Call Loop

```go
type WeatherArgs struct {
    City string `json:"city" jsonschema:"description=City name, e.g.: Beijing"`
    Unit string `json:"unit,omitempty" jsonschema:"description=Temperature unit,enum=celsius,enum=fahrenheit"`
}

weather := callable.NewTool("get_weather", "Get the real-time weather for a given city",
    func(ctx context.Context, args WeatherArgs) (any, error) {
        return fmt.Sprintf("%s is currently 26°C and sunny", args.City), nil
    })

agent := callable.NewAgent(client,
    callable.WithSystemPrompt("You are a pragmatic assistant"),
    callable.WithTools(weather),
    callable.WithThinking(callable.Thinking{Effort: callable.EffortMedium}),
    callable.WithMaxTurns(25),
    // Optional: approval hook before execution
    callable.WithToolCallHook(func(ctx context.Context, call callable.ToolCall) (callable.ToolDecision, error) {
        return callable.Approve(), nil // or Deny("reason") / ReplaceArgs(`{"city":"Shanghai"}`)
    }),
)

// Run internally executes: model -> tools -> model -> ... until the final answer
result, err := agent.Run(ctx, callable.User("How's the weather in Beijing?"))
// result.FinalText / result.Messages (full trajectory) / result.Usage (accumulated) / result.Turns
```

### Streaming Run (Fully Visible)

```go
result, err := agent.RunStream(ctx, func(ev callable.Event) {
    switch e := ev.(type) {
    case callable.ThinkingDeltaEvent: // thinking delta
    case callable.TextDeltaEvent:     fmt.Print(e.Delta) // text delta
    case callable.ToolCallEvent:      // a tool is about to execute
    case callable.ToolResultEvent:    // a tool finished executing
    case callable.TurnStartEvent:     // turn e.Turn begins
    }
}, callable.User("How's the weather in Beijing?", callable.Image("/tmp/screenshot.png")))
```

### Multi-Turn Sessions

```go
sess := agent.Session(
    callable.WithContextWindow(200_000),   // context window, default 1M
    callable.WithAutoCompact(true),        // auto-compact history at the threshold, default off
)
sess.Ask(ctx, callable.User("What about Shanghai?"))   // history maintained automatically
sess.AskStream(ctx, handler, callable.User("And Guangzhou?"))
sess.ContextFillRatio() // current context fill ratio
sess.Compact(ctx)       // compact history manually
sess.ID()               // conversation ID (sess- prefix), carried by all events and the AgentResult
data, _ := sess.Snapshot() // persist the whole session (id + history + context usage)
sess.Restore(data)      // restore from a snapshot
sess.History()          // []Message, or serialize it yourself
sess.SetHistory(saved)  // restore history manually
```

## Skills: Progressive Disclosure

```go
skill := callable.NewSkill("pdf-export", "Export data to a PDF file",
    "# Full instructions… (only read when the model calls read_skill)")

agent := callable.NewAgent(client,
    callable.WithSkills(skill),
    // Read hook: rewrite the content before returning it to the model
    // (append runtime context, lazily load sub-files, audit)
    callable.WithSkillReadHook(func(ctx context.Context, name, content string) (string, error) {
        return content + "\n\nCurrent time: " + time.Now().Format(time.RFC3339), nil
    }),
)
```

Only an index appears in the system prompt:

```
<available_skills>
The following skills are available. When a task may benefit from a skill, first call the
read_skill tool to load its full instructions, then follow them.

- pdf-export: Export data to a PDF file
</available_skills>
```

The built-in tool is named `read_skill` by default; rename it with `WithSkillToolName`, or disable it with `WithSkillToolDisabled` and register your own replacement tool.

## Sub-Agents: Delegation

```go
translator := callable.NewSubAgent("translator", "Translate Chinese into idiomatic English",
    callable.WithSubAgentModel("gpt-5-mini"),               // pick a model (reuses the parent client's endpoint and key)
    callable.WithSubAgentPrompt("You are a professional translator…"), // pick a prompt
)

researcher := callable.NewSubAgent("researcher", "Research a topic in depth",
    callable.WithSubAgentClient(otherClient),   // or swap in an entirely different client/provider
    callable.WithSubAgentTools(searchTool),     // pick tools (invisible to the parent agent)
    callable.WithSubAgentSkills(citingSkill),   // pick skills (sub-agent comes with its own read_skill)
    callable.WithSubAgentThinking(callable.Thinking{Effort: callable.EffortHigh}),
    callable.WithSubAgentMaxTurns(10),
)

agent := callable.NewAgent(client,
    callable.WithSystemPrompt("Delegate translation to translator and research to researcher"),
    callable.WithSubAgents(translator, researcher),
)
```

Like skills, sub-agents use progressive disclosure: **sub-agents are not loaded into the tool list by default** — only a name/description index is injected into the system prompt:

```
<available_agents>
The following sub-agents are available for delegating subtasks. They are NOT
loaded as tools yet. When a subtask matches one of them, first call the
load_agent tool with the sub-agent's name to load it; this registers a
call_<name> tool, which you then call with a self-contained task description.

- translator: Translate Chinese into idiomatic English
- researcher: Research a topic in depth
</available_agents>
```

Delegation is a two-step process, both driven by the model:

1. **Manual load**: the model calls the built-in `load_agent` tool → returns the sub-agent's full card (description, prompt, capability list) and **dynamically registers** a `call_<name>` tool, which becomes visible to the model from the next request onward.
2. **Invocation**: the model calls `call_<name>({"task": "..."})` → the sub-agent runs its own agent loop in a fresh session (with its own model/tools/skills), and its final answer is returned to the parent agent as the tool result.

Behavior details:

- Loading is idempotent: once loaded, `call_<name>` stays available; if it collides with a user-defined tool of the same name, loading fails with an error instead of overwriting.
- Calling `call_<name>` before loading yields an unknown-tool error (it really isn't in the tool list).
- The built-in tool is named `load_agent` by default; rename it with `WithSubAgentToolName`, or disable it with `WithSubAgentToolDisabled` and register your own replacement.
- Sub-agents do not inherit the parent agent's sub-agent list (no nesting); every invocation runs in a fresh session with no shared history.
- When a sub-agent hits max turns, its partial answer so far is returned to the parent agent with a note, instead of failing outright.
- Event forwarding: by default, a sub-agent's internals are invisible to the parent agent's event callback; with `WithSubAgentEvents(true)`, the sub-agent switches to streaming execution and each of its events is wrapped in a `SubAgentEvent` (carrying the sub-agent name and the raw event) and forwarded to the parent agent's event callback, letting consumers distinguish main vs. sub-agent output.

## Thinking Mode

```go
callable.WithThinking(callable.Thinking{Effort: callable.EffortHigh})     // low / medium / high
callable.WithThinking(callable.Thinking{BudgetTokens: 16000})             // explicit budget for Anthropic / Qwen
```

| Provider | Request field | Notes |
|---|---|---|
| Anthropic | `thinking.budget_tokens` | effort maps to 2048/8192/16384; max_tokens is automatically kept above budget |
| OpenAI Responses | `reasoning.effort` | ships with `summary: "auto"` to stream thinking summaries |
| OpenAI Chat Completions | `reasoning_effort` | |
| GLM / Zhipu (incl. Z.AI) | `thinking:{type:"enabled"}` + `reasoning_effort` | auto-sniffed from BaseURL; medium→high (GLM-5.3 rejects medium); ⚠️ GLM-5.3 forces thinking on — sending disabled yields a 400 |
| Volcano Ark | `thinking:{type:"enabled"}` + `reasoning_effort` | auto-sniffed from BaseURL; effort passed through as-is |
| Qwen (DashScope) | `enable_thinking:true` + `thinking_budget` | auto-sniffed from BaseURL; `BudgetTokens` maps to thinking_budget |
| DeepSeek | `thinking:{type:"enabled"}` + `reasoning_effort` | auto-sniffed from BaseURL; thinking on by default (effort high) — pass `Thinking{}` to explicitly disable; medium maps to high server-side |

Thinking content is fully preserved in history and sent back on the next turn (Anthropic needs the signature, Responses needs the reasoning item, Chinese endpoints need reasoning_content), so thinking is never lost across the tool loop.

## Image Input

```go
callable.Image("/tmp/screenshot.png")     // local path: read file + detect type + base64
callable.Image("https://cdn/x.jpg")       // URL passed through as-is
callable.ImageBytes(data, "image/png")  // raw bytes (mediaType must be a full MIME type)
callable.User("What's in this picture?", callable.Image("/tmp/a.png"))  // mixed text + image
```

The same message history can be sent to any provider — it is converted to the corresponding format at send time (Anthropic base64 source / OpenAI data URL).

## Event Reference

| Event | Level | Description |
|---|---|---|
| `TurnStartEvent` / `TurnEndEvent` | agent | turn start / end |
| `MessageStartEvent` | provider | an assistant message begins |
| `ThinkingDeltaEvent` | provider | thinking text delta |
| `TextDeltaEvent` | provider | text delta |
| `ToolCallDeltaEvent` | provider | tool name / arguments JSON delta |
| `MessageDoneEvent` | provider | complete message + this turn's Usage |
| `ToolCallEvent` | agent | complete tool call (before execution) |
| `ToolResultEvent` | agent | tool execution result |
| `AgentDoneEvent` | agent | loop finished (carries the AgentResult) |

## Error Handling

- `*callable.APIError`: `Provider / StatusCode / Type / Message / Body`; `IsRetryable()` tells whether it can be retried.
- Network errors / 429 / 5xx are retried automatically (3 retries by default, waiting 3s / 10s / 30s; configure with `WithRetries(n)`, disable with `WithRetries(0)`, customize the schedule with `WithRetryBackoff(d...)`).
- Tool execution errors → returned to the model as an `IsError` tool result (so it can retry or take another path) without breaking the loop.
- `*callable.MaxTurnsError`: carries `Partial *AgentResult`.
- Per-request escape hatch: `NewRequest(...).WithExtra("key", value)` passes any top-level field through.
- Header pass-through: `NewRequest(...).WithHeader(k, v)` sends custom HTTP headers per call; for every request use the client-level `WithClientHeader` or the provider-level `WithHeader`.

## Cancellation & Timeouts (Graceful Shutdown)

All calls are driven by `context.Context`. Cancellation (or timeout) behaves **gracefully**:

- **Upstream stops too**: in-flight HTTP/SSE connections are closed immediately, so the server notices the disconnect and stops generating (no more token charges).
- **No new requests**: the agent loop checks the context before each turn and will not start a new model call after cancellation.
- **Partial results are kept**: when a stream is cancelled midway, `Stream` / `RunStream` return a **non-nil partial result** (the text generated so far, the Usage accumulated so far), and the error satisfies `errors.Is(err, context.Canceled)` / `context.DeadlineExceeded`.
- **Tool pairing stays complete**: unexecuted tool calls get a synthesized `IsError` result ("tool execution skipped: ..."), so every tool_call has a matching tool_result and the partial trajectory remains a valid, replayable conversation.
- **Sessions stay clean**: an aborted run is not written into the session history.

```go
ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
defer cancel()

result, err := agent.RunStream(ctx, onEvent, callable.User("..."))
if errors.Is(err, context.DeadlineExceeded) {
    // result is non-nil: result.FinalText holds the partial text generated so far
}
```

Note: a running tool function receives the same ctx — tool implementations should respond to cancellation themselves (database queries, sub-requests); Go cannot forcibly kill a goroutine that ignores ctx.

## Design Notes

- **Unified message model**: internally there is only one `Message{Role, Parts}`, with Part as a closed type family (Text/Image/Thinking/ToolCall/ToolResult). Each provider handles two-way conversion; business code never sees wire formats.
- **Faithful history round-trips**: assistant messages can carry per-provider raw data (`Message.SetProviderExtra`), e.g. sending Responses' reasoning item back verbatim; `Message` supports full JSON serialization round-trips and can be persisted.
- **Single entry point**: the implementation is split by concern into internal packages (`internal/model`, `internal/provider`, `internal/client`, `internal/skill`, `internal/agent`); the root package's `callable.go` is the only public entry (a full re-export) — one import gives you everything.
